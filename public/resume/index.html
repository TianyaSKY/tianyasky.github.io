SKYDouyin —— 短视频推荐系统

项目负责人

技术栈：Spring Boot · FastAPI · PyTorch · Milvus · Redis · MySQL · RabbitMQ github.com/TianyaSKY/SKYDouyin

视频召回与融合排序：Web 与 Android 都会上报播放、停留和点赞。推荐服务根据这些行为生成 1024 维向量，再与热门池、长短期偏好一起融合排序，完成个性化推荐。只靠向量召回时，头部内容不一定进得了候选，因此热门池单独保留一路。

事件解耦与冷启动推荐：视频发布后，由 RabbitMQ 把向量生成事件交给 FastAPI 推荐服务，写入 Milvus，业务请求不必等待模型算完。新用户还没有行为时，定时把已发布视频的标签向量聚合进 Redis；用户勾选兴趣后取这些向量的均值作为初始画像，避免冷启动阶段出现空推荐。

高并发互动与幂等防重：点赞和收藏以用户与视频的联合唯一键作为真相表，重复点击不会插入第二条关系。计数不随每次点击直接写 MySQL，先在 Redis 中累加，再定时批量回写，避免高频互动把数据库写满。Spring Boot 维护用户、视频和关系数据，FastAPI 只负责向量，业务服务、推荐服务和消息消费各自保留边界。

分片上传：上传前先计算文件哈希，再依次完成初始化、分片、合并和元数据创建；相同哈希可以直接秒传。合并完成后再异步生成 Embedding，上传接口本身不等待模型返回。
